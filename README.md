# Adesso vinco io

Tracker per seguire la schedina durante le partite: giocate da spuntare, contatori per goal, angoli e cartellini, tendine per ogni partita e animazioni quando vinci.

È una singola pagina (`index.html`), senza build e senza dipendenze da installare. I dati restano salvati nel browser del dispositivo che usi.

## Pubblicarla con GitHub Pages

1. Crea un nuovo repository su GitHub.
2. Carica i file di questa cartella nella radice del repository.
3. Vai in **Settings > Pages**.
4. In **Source** scegli **Deploy from a branch**, poi il branch `main` e la cartella `/ (root)`, e salva.
5. Dopo un minuto circa la pagina è online su `https://TUO-UTENTE.github.io/NOME-REPOSITORY/`.

## Uso in locale

Apri `index.html` con un doppio clic nel browser.
